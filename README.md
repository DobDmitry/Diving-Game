# Вышка 10 м — Android

Игра целиком лежит в `app/src/main/assets/index.html` и работает офлайн.
Нативная часть — одна `Activity` с `WebView`, разрешение на интернет приложению не нужно.

## Как получить APK

Сборка идёт на серверах GitHub, ставить Android SDK на свою машину не требуется.

1. Создайте на github.com пустой репозиторий (например `diving-10m-android`),
   **без** README, .gitignore и лицензии.
2. Выполните в этой папке:

   ```
   git remote add origin https://github.com/ВАШ_ЛОГИН/diving-10m-android.git
   git branch -M main
   git push -u origin main
   ```

3. На странице репозитория откройте вкладку **Actions** — сборка «Сборка APK»
   запустится сама. Идёт 3–5 минут.
4. Внутри завершившегося запуска внизу будет блок **Artifacts** →
   `diving-10m-apk`. Скачается zip, внутри `diving-10m-ГГГГММДД-debug.apk`.

Дальше сборку можно запускать вручную кнопкой **Run workflow** на вкладке Actions.

## Как поставить на телефон

APK отладочный, поэтому Android попросит разрешить установку из неизвестного
источника: Настройки → Приложения → Особые разрешения → Установка неизвестных
приложений → разрешить браузеру или файловому менеджеру.

Отладочная подпись не годится для Google Play, но для установки на свои
устройства и раздачи команде подходит.

## Как обновить игру

Заменить `app/src/main/assets/index.html` на новую версию, поднять `versionCode`
и `versionName` в `app/build.gradle`, закоммитить и запушить — сборка стартует сама.

## Что делает нативная часть

Всё, чего HTML не может сам:

- принудительный портретный режим;
- двойное нажатие «Назад» для выхода, чтобы не вылететь посреди прыжка;
- экран не гаснет во время игры;
- `localStorage` включён — рекорды переживают перезапуск;
- звук стартует без отдельного жеста;
- отключены зум, выделение текста и подсветка нажатий.

## Версии инструментов

Android Gradle Plugin 8.5.2, Gradle 8.7, JDK 17, compileSdk 34, minSdk 26 (Android 8.0).
